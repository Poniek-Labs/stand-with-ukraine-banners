# What is this?
This is a banner for a website, displaying support for ukraine and a link to the official ukraine.ua website.
## How do i use this?
inside this folder there is a file called """ banner.html """ <-- copy and paste the contents of """ banner.html """ into your html file, you can put it
inside an existing <div> tag, or just anywhere in the code, just keep in mind that it will appear under whatever block of code you have above it, so if you want it at the top
of your page put it at the very top of <body> and if you want it at the bottom put it at the very bottom of <body>, just above </body>.

## Where does the link go?
The link in the banner goes to the official government website of ukraine.
